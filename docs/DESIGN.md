# 새벽까지 (Till Dawn) — Game Design Brief

> Netflix 드라마 **킹덤**에서 영감을 받은 조선 시대 좀비 생존 액션. 독창 설정·명칭으로 재구성.
> 세계·그래픽 기반: 사용자 자작 [처마(cheoma)](../asiahouse) 조선 마을 생성기 재사용 (저작권 자유).

## Player Promise (한 문장)

"당신은 역병이 덮친 마을의 장수. 해가 지기 전에 준비하고, 원귀의 밤을 새벽까지 버텨라."

## Target Feeling

- 낮: 고요하고 서늘한 긴장 (잠든 원귀들이 지축에 널브러져 있다)
- 해질: 경보 북 소리와 함께 번지는 공포
- 밤: 하얀 눈동자의 강처럼 밀려드는 군단과의 광란
- 새벽: 찬 기운에 원귀가 얼어붙고 찾아오는 안도

## Primary / Secondary Verbs

- **주동사: 베다(slash)** — 부채꼴 즉발 타격 + 넉백. 사거리 짧고 강력.
- 보조동사: **쏘다(bow)** — 모아 쏘는 관통 화살(탄약 제한), **회피(dash)** — 무적 프레임 이동,
  **화톳불 점화(E)** — 공포 영역 생성, **줍기(E)** — 화살궤/횃불 획득.

## Core Loop Contract (5–30초)

```
플레이어는 [베기/활/회피]로 [새벽까지 생존]을 추구하고,
[사방에서 몰려드는 원귀 군단 + 한정된 화살]이 위험을 만든다.
성공은 [처치 점수 + 마을 주민 구출 + 다음 낮의 자원]을 주고,
실패는 [즉시 재시작 가능한 죽음 화면]으로 이어진다.
```

## Day Cycle (진행 루프, 1~5분)

| 페이즈 | 길이 | 내용 |
|---|---|---|
| 낮 (day) | 35s | 압축된 약탈: 화살궤, 횃불, 화톳불 점화, 주민 호위. 잠든 원귀는 밟으면 깨어난다 |
| 해질 (dusk) | 10s | 북 울림. 처마(time=sunset) 전환. 마지막 준비 창 |
| 밤 (night) | 150s | **단일 방위 강(江)**: 13초마다 한 능선에서 3연속 rip(55/30/15%)가 쏟아진다. 밤이 깊을수록 굵어진다 |
| 새벽 (dawn) | 15s | 찬 기운 — 남은 원귀 동결·소멸(얼음눈 신호). **로거라이트 3택 강화** |

- 난이지 곡선: 밤 N마다 강 폭 증가(26+12N+10×웨이브, 상한 130), 밤 3+ 처녀귀(빨간 눈, 돌진형 등장)
- 경제: 화살(재생 느림 + 필드 획득), 횃불(근접 화염 강화 1회), 체력(주민 구출 보너스)
- 전투 감각: 타격 시 스태거(일반 0.3s/처녀귀 0.14s)+타임스케일 히트스톱(0.07s)+trauma 셰이크; 3초 내 연속 처치=연살(피해 +10%×연삭, 상한 12)·FOV 펀치
- 새벽 강화(6종 중 3택): 벼려낸 환도(+35% 피해) · 그을린 화살촉(관통+1·화살+8) · 바람걸음(+12% 이동·회피 -25%) · 타오르는 화톳불(+40% 반경·지속) · 생명의 샘(+30 최대기력·회복) · 참수의 흐름(연살 +2초·위력 +50%)

## 킹덤에서 가져온 시그니처 메커니즘 (드라마 공식 → 게임 규칙)

1. **야간 활성 / 주간 동면** — 낮에는 원귀가 땅에 엎드어 잠들고(밟으면 발각), 밤에 일제히 기상
2. **물 = 생존** — 개울 물속에서는 원귀가 플레이어를 감지하지 못한다. 유인 후 도주 전술
3. **한기 = 새벽** — 새벽 한파에 원귀가 얼어붙는다 (드라마 1기 결말의 역전)
4. **강처럼 흐르는 군단** — 언덕을 넘어 쏟아지는 원귀 강(InstancedMesh 수백) = 바이럴 스샷 모먼트
5. **소리의 위험** — 활 소리는 주변 원귀를 끌어들인다 (risk/reward)

## Level / Encounter Plan

- **공간**: 처마 생성 마을(seed 고정, 마을 등급 siteR 중간, 개울 on, 사찰 on)
- **시작점**: 마을 중심 공터(당산나무 근처). 첫 결정 10초 내: "화살을 줍고 화톳불을 켤 것인가, 주민부터 구할 것인가"
- **첫 위협**: 해질 첫 웨이브 6마리 — 서쪽 숲 능선에서. 이후 4방위 순환
- **랜드마크**: 당산나무(중심), 절(북고지), 개울(남동 흐름), 논밭(외곽)
- **회복 비트**: 새벽 페이즈, 화톳불 반경, 개울
- **가독성**: 밤 원귀 눈 발광(광원 아님, emissive), 시간은 하늘·햇빛 각도로, 웨이브 방향은 북+소리 큐
- **실패 가독성**: 피격 방향 붉은 비네트 + 히트스톱, 죽음 원인 문구 표시

## Skill Expression

- 무리 밀어내기 각도잡기(베기 넉백으로 코스 만들기), 화톳불 위치 선점, 개울 유인, 활 헤드샷 관통
- 고수는 더 적은 화살로 더 많은 관통 처치 점수

## Fail / Retry

- HP 0 → "새벽을 못 보았다" + 생존 일수/처치/구출 기록 → R 또는 버튼으로 즉시 재시작(3초 내)

## Non-goals (이 슬라이스)

- 멀티플레이어, 세이브/메타 진행, 컷신, 음성, 보스(처녀귀 정도까지)

## Performance / Device Budget

- 데스크톱 + 모바일 브라우저, WebGL2, DPR ≤ 2
- 활성 원귀 ≤ 250 (InstancedMesh 1드로우) + 원거의 임포스터
- 드로우콜 < 400, 60fps 목표 (모바일 30fps 하한)
- 처마 마을 LOD/청크 시스템 그대로 수용

## Audio (절차적 WebAudio — 키 불필요)

- 북(해질), 바람/귀뚜라미(밤), 검격/활시위/화살, 원귀 신음(군단 다성), 심박(저체력), 새벽 종소리
- 처마 앰비언스(풍경·개울·개 짖음) 재사용 가능 시 통합
